Privacy Policy: Roblox Vault Sync

Last updated 2026-10-29.

Roblox Vault Sync is a personal tool used only by its owner.

  • It reads and writes files in the owner's own Google Drive, only to keep a copy of the owner's own project files.
  • It runs on the owner's computers. It has no server and collects no data.
  • It shares nothing with anyone. It sells nothing. It shows no ads.
  • The owner can remove its access at any time at myaccount.google.com/permissions.

Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
